Política de Privacidade

Esta Política de Privacidade explica como o Sistema de Apoio Bibliográfico para PFCs coleta, utiliza, armazena e protege dados pessoais de seus usuários.

1. Dados coletados

O sistema poderá tratar os seguintes dados:

  • Nome;
  • E-mail;
  • Senha, armazenada de forma protegida por hash;
  • Curso;
  • Disciplina;
  • Tema do PFC;
  • Área de conhecimento;
  • Palavras-chave;
  • Registros de acesso e ações realizadas no sistema.

2. Finalidades do tratamento

Os dados são utilizados para:

  • Realizar o cadastro e autenticação dos usuários;
  • Controlar o acesso às funcionalidades do sistema;
  • Armazenar informações dos Projetos de Final de Curso;
  • Permitir consultas aos PFCs cadastrados pelo próprio usuário;
  • Realizar buscas bibliográficas relacionadas aos temas informados;
  • Manter registros de auditoria e segurança;
  • Melhorar o funcionamento e a segurança do sistema.

3. Armazenamento e segurança

As informações são armazenadas no banco de dados do sistema. As senhas dos usuários não são armazenadas em texto puro, sendo protegidas por função de hash.

O sistema utiliza autenticação, controle de acesso e registros de auditoria para auxiliar na proteção das informações.

4. Integração com API externa

O sistema utiliza a API OpenAlex para realizar buscas bibliográficas relacionadas aos temas e palavras-chave informados pelo usuário.

Para essa finalidade, são enviados termos relacionados à busca bibliográfica. O sistema não envia senha, e-mail ou outras informações de autenticação do usuário para a OpenAlex.

5. Registros de auditoria

O sistema mantém registros de determinadas ações realizadas pelos usuários, como login, logout, cadastro de PFCs, consultas e buscas bibliográficas.

Esses registros têm finalidade de segurança, controle e rastreabilidade das operações realizadas no sistema.

6. Direitos do titular

Nos termos da LGPD, o titular possui direitos relacionados ao tratamento de seus dados pessoais, incluindo, conforme aplicável, confirmação da existência de tratamento, acesso, correção de dados, informações sobre compartilhamento, anonimização, bloqueio ou eliminação nas hipóteses previstas na legislação e revogação do consentimento quando essa for a base legal aplicável.

As solicitações relacionadas aos dados pessoais devem ser encaminhadas ao responsável pelo sistema.

7. Dados pessoais sensíveis

O sistema não solicita dados pessoais sensíveis para a realização de suas funcionalidades principais.

8. Compartilhamento de dados

Os dados pessoais não são destinados à divulgação pública. A integração com a OpenAlex é utilizada especificamente para pesquisas bibliográficas e não recebe dados de autenticação dos usuários.

9. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada para refletir alterações nas funcionalidades do sistema ou nas práticas de tratamento de dados.

10. Acesso à política

Esta página permanece disponível aos usuários para consulta sempre que necessário, inclusive antes da realização do login.
